# RoboFriends

A simple React application that displays a list of "robot friends" fetched from an external API. Users can search through the list to filter the robots by name.

![RoboFriends Screenshot Placeholder](https://iamkartikey.vercel.app/project-screenshots/robofriends.png)

## Features

- Displays a list of robot cards with names, usernames, and emails.
- Fetches user data dynamically from the [JSONPlaceholder](https://jsonplaceholder.typicode.com/) API.
- Uses dynamic robot images generated by [robohash.org](https://robohash.org/).
- Real-time search functionality to filter robots by name.
- Simple, responsive layout using Tachyons CSS toolkit.
- Custom "SEGA" style font for the main title.
- Built with Create React App.

## Tech Stack

- **Frontend:** React.js (v18)
- **Styling:** Tachyons, CSS (including custom fonts)
- **API:** Fetch API (native browser API)
- **Data Source:** JSONPlaceholder (for user data), RoboHash (for images)
- **Build Tool:** Create React App (react-scripts)
- **Package Manager:** npm

## Setup Instructions

To get a local copy up and running, follow these simple steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/awesome-kartikey/robofriends.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd robofriends
    ```
3.  **Install NPM packages:**
    ```bash
    npm install
    ```
4.  **Start the development server:**
    ```bash
    npm start
    ```
    This runs the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will reload when you make changes.

## Usage

Once the application is running:

1.  You will see a list of robot cards.
2.  Use the search box at the top to type a robot's name.
3.  The list will filter in real-time to show only the robots matching your search query.
